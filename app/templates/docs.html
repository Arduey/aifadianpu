商户使用说明

爱发电铺帮你把虚拟商品（卡密、授权、素材、教程…）挂到你自己的爱发电账号下销售。消费者无需注册，在你店铺页选商品、扫码付款；钱直达你的爱发电，平台不经手资金。支付成功后平台会自动通知你（Webhook / 邮件），你能据此自动发货。

1 · 快速开始（三分钟开店）

  1. 注册：用 {% if allow_email_domains %}{{ allow_email_domains | join(' / ') }}{% else %}任意{% endif %} 邮箱注册，起一个唯一店铺名（首位注册者即管理员）。注册即送 ¥{{ '%.2f'|format(api_fee) }} 体验额度。
  2. 绑定爱发电：在控制台个人中心填写爱发电 user_id 与 token（必填，否则无法创建和销售商品）。详见 第 4 节。
  3. 上架商品：填 分类 / 标题 / SKU / 价格（规则见 第 3 节）。
  4. 拿到店铺链接：形如 /shop/你的爱发电user_id，复制后分享给顾客。
  5. 顾客下单：顾客选商品 → 扫码付款 → 平台每 5 秒确认到账 → 支付成功通知你，你发货。

2 · 店铺设置

  • 店铺名：注册时确定，需全平台唯一。
  • LOGO / 简介：在个人中心设置。未设 LOGO 时会回退平台默认 LOGO。简介支持多行。
  • 店铺链接：/shop/{你的爱发电 user_id}。可在个人中心查看复制，也是分享给顾客的地址。
  • 前台长什么样：左侧分类目录、右侧商品卡（只显示 SKU 文本），顶部店铺信息与客服联系方式。
  • 已完整适配手机 / 平板 / PC：前台店铺对三种设备都已做响应式适配，顾客用手机、平板还是电脑打开，都能正常浏览商品并顺畅下单——你无需为不同设备做任何额外设置。
    • 手机（≤640px）：分类目录收起为下拉选择，商品改为单列大卡，店铺信息与商品区纵向排列，付款弹窗自适应铺满宽度；
    • 平板 / 窄屏（641–767px）：商品两列展示，分类目录仍在左侧；
    • PC（≥768px）：商品三列、分类目录在左侧常驻，内容居中限宽，长列表在商品区内滚动；
    • 图片与付款二维码均等比缩放不溢出，滚动条已美化，点击区域按手指 / 鼠标分别留足。

预览前台店铺（管理员示例）：/shop/{{ previewShopUid }}

3 · 商品管理

  • 字段：分类、分类图标、标题、SKU 名、价格。
  • 价格：整数，≥ 5 元（5 元是爱发电「自选发电」的最低限额，平台据此设定最低价）。
  • 判重：同一店铺内，分类 + 标题 + SKU 三字段完全相同即视为重复，不能保存。
  • 禁止字符：分类 / 标题 / SKU 中都不能含 &（会导致下单参数解析异常）。
  • 排序 / 编辑 / 删除：控制台商品页用 ↑ / ↓ 按钮上移、下移调整顺序（改完自动保存），并可编辑、删除。
  • 上架后：按分类分组展示在店铺页。
  • 「API充值」分类：仅管理员可创建。管理员在该分类下建的商品会自动成为充值项（不在顾客店铺页显示）；普通商户即使建同名分类，也只当普通商品处理。

4 · 绑定爱发电（必读）

  • 在哪获取：登录爱发电 → 开发者页面 https://ifdian.net/dashboard/dev，user_id 与 token 都在这里查看 / 生成。
  • user_id：你的爱发电用户 id，用来定位店铺页（前台地址即 /shop/你的user_id）。
  • token：开放平台给你的商户凭证，用于查询订单的付款状态与信息（不是用来下单的）。实际下单由平台管理员配置的「消费者账号」完成。
  • 不绑定的后果：无法创建商品、无法销售。
  • 绑定失败常见原因：id / token 填反或多了空格；爱发电侧未开通开放平台。
  • 绑定后的状态：控制台个人中心会显示绑定徽标；可点「连接测试」验证是否可用。
下单由平台管理员配置的「消费者账号」完成；平台会自动维护它的登录，过期自动重登。你的 token 只用于查询该账号在你店铺下的订单状态 / 信息。

5 · 收款与到账

  • 资金流向：顾客付款 → 直达你的爱发电账号，平台不经手、不托管资金。
  • 付款方式：微信 / 支付宝；若某方式被平台暂时关闭，店铺页会显示不可用并给出说明。
  • 订单流转：待支付 → 已支付。顾客扫码后，店铺页每 5 秒轮询确认；确认到账后触发通知（Webhook + 邮件）。

6 · 自动发货（Webhook）

订单支付成功后，平台会主动向你填写的回调地址发一次请求，把订单数据推给你——收到即可自动发卡 / 发权益，无需轮询。

  • 在哪配置：控制台 →「个人中心 / 平台配置」→ Webhook 区域。可设回调地址、请求方法、编码、请求头、查询参数、正文模板；填好可点「发送测试」验证。
  • 何时触发：订单由「待支付」变「已支付」时触发一次（同订单只推一次）。
  • 编码可选：JSON / form-urlencoded / 文件(二进制) / RAW 文本。
  • 可用变量（正文模板里写 @变量 会被替换为真实值）：
    变量含义
    @order_id订单号（用它去重 / 查单）
    @creat_time下单时间
    @type商品分类
    @title商品标题
    @skuSKU 名称
    @total金额（元）
    @seller商户标识（爱发电 user_id）
  • 你该返回什么：HTTP 2xx 视为成功；失败可在后台「Webhook 历史」查看原因并重试。
POST /webhook            # 你实现的接收端点
Content-Type: application/json

{
  "order_id":   "AFD2026021400001",
  "creat_time": "2026-02-14 15:30:00",
  "type":       "图标素材",
  "title":      "Morph 线性图标包",
  "sku":        "SVG全量版",
  "total":      18,
  "seller":     "afdian_pixellab_88"
}

# 建议：用 order_id 去重后发货 / 记单，返回 {"ok": true}

7 · 邮件通知

  • 订单通知邮件：每笔支付成功给你发一封（可在个人中心开关、预览、发测试，测试每日 1 次）。
  • API 余额不足提醒：余额低于阈值时提醒你充值（同样支持开关 / 预览 / 测试）。
  • 邮件与 Webhook 相互独立，可只开其一，也可都开。

8 · API 余额与充值

  • 为什么会扣费：每笔成功订单，平台收取 ¥{{ '%.2f'|format(api_fee) }} 服务费（平台对接爱发电接口的服务开销）。
  • 余额从哪来：注册赠送 + 你自己充值。
  • 余额不足：会拦下新订单，并给你发余额不足邮件；请及时充值。
  • 怎么充值：控制台「充值」→ 选充值商品与付款方式 → 扫码 → 支付成功后即时到账。

9 · 订单管理

  • 订单列表：显示已付款与待支付订单，支持按关键词 / 付款方式筛选；待支付超过 3 小时的订单会被自动清理，不再保留。
  • 字段含义：订单号、下单时间、商品分类 / 标题 / SKU、金额、付款方式、卖家（商户 user_id）。
  • 与通知的关系：订单支付成功时，同时触发 Webhook 与订单邮件；订单列表是历史留档。

10 · 常见问题

下单提示“店铺余额不足”？
你账户余额低于单次服务费时会被拦下、无法下单，请到控制台充值；余额低于你设置的提醒阈值时会收到余额不足提醒（不拦单）。
顾客扫码后一直“等待支付”？
多为未真正完成付款；页面会每 5 秒自动确认，付款成功后自动转为已支付。
没收到 Webhook？
到「Webhook 历史」看投递结果与原因；确认地址可公网访问、返回 2xx。
忘记密码怎么办？
登录页「忘记密码」，用注册邮箱收重置链接（10 分钟内有效）。
店铺没出现在店铺广场？
需满足：店铺状态正常且已绑定爱发电 user_id。
注销账号会怎样？
账号停用、数据保留；仅管理员可重新启用。
