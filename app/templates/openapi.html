开放接口

面向商家与第三方接入的公开业务接口：店铺信息、商品列表、下单、支付轮询与订单查询。所有返回统一为 JSON；错误时 HTTP 状态码非 2xx，body 带 {"ok": false, "message": "…"}。

一、店铺信息（公开）

GET公开

平台已开店商户列表（状态正常且已绑定爱发电）。用它找到你自己店铺的 afdian_user_id，再拿去查商品 / 下单。

请求示例
GET
响应示例
{
  "ok": true,
  "shops": [
    {
      "shop_name": "PixelLab",
      "shop_logo_url": "/static/…",
      "bio": "图标素材与设计资源",
      "afdian_user_id": "afdian_pixellab_88",
      "product_count": 12
    }
  ]
}
GET公开

平台客服邮箱。买家遇到问题时，可展示此联系方式。

请求示例
GET
响应示例
{ "ok": true, "email": "admin@example.com" }
GET公开

获取店铺在售商品列表——这就是下单要用的 product_id 的来源。先调它拿到 id，再传给 /shop/buy。

查询参数（uid / shop / email 三选一）
参数类型必填说明
uidstring三选一商户的爱发电 user_id（取 /api/shops 返回的 afdian_user_id）
shopstring三选一店铺名
emailstring三选一商户邮箱（商户注册/登录用的邮箱）
请求示例
GET ?email=merchant@example.com
响应示例
{
  "ok": true,
  "shop_name": "PixelLab",
  "afdian_user_id": "afdian_pixellab_88",
  "products": [
    { "id": 1, "category": "图标素材", "title": "Morph 线性图标包", "sku_name": "SVG全量版", "price": 18 }
  ]
}

二、下单与支付（公开）

POST公开

为买家创建订单。先用 GET /api/products 拿到 product_id，再调本接口下单；返回的 qrPayload 用来生成收款二维码给买家扫。

请求体（JSON）
字段类型必填说明
product_idint是商品 ID，取值见 GET /api/products 返回的 products[].id
channelstring是wechat | alipay
请求示例
POST 
Content-Type: application/json

{ "product_id": 1, "channel": "wechat" }
响应示例
{ "orderNo": "AFD2026021400001", "qrPayload": "weixin://…", "total": 18 }
GET公开

买家扫码付款后，轮询此接口确认是否到账（建议每 5 秒一次）。返回 status=paid 即已支付，此时可发货 / 发权益。

路径参数
参数类型必填说明
order_nostring是下单返回的订单号
请求示例
GET AFD2026021400001
响应示例
{
  "status": "pending"   // pending | paid
}
GET公开

凭商户邮箱 + 订单号核对这笔订单是否已支付（发货前核验、售后对账用）。仅返回已支付订单。

查询参数
参数类型必填说明
emailstring是商户邮箱（商户注册/登录用的邮箱）
order_nostring是订单号
请求示例
GET ?email=merchant@example.com&order_no=AFD2026021400001
响应示例
{
  "ok": true,
  "data": {
    "order_id":   "AFD2026021400001",
    "creat_time": "2026-02-14 15:30:00",
    "type":       "图标素材",
    "title":      "Morph 线性图标包",
    "sku":        "SVG全量版",
    "total":      18,
    "seller":     "afdian_pixellab_88"
  }
}
